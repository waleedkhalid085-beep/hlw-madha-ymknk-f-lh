# منصة COREX للعمليات البترولية وحقول النفط (Laravel 11 Enterprise Edition)
### COREX Enterprise Operations Platform - Lion Oilfield Services Iraq

نظام متكامل صُمم ليتفوق على النسخة السابقة بمظهر فخم ومستوى أمان وإدارة عالي لعمليات رؤوس الآبار، المستودعات، والكوادر الميدانية.

---

## 🌟 مميزات التصميم والوظائف المطورة:
1. **واجهة دخول فخمة وتفاعلية:**
   * تصميم ملكي كحلي داكن ( / ) ولمسات ذهبية عيار 24 قيراط ().
   * تأثيرات إضاءة ديناميكية وخلفيات زجاجية معتمة (Frosted Glassmorphism).
   * زر الدخول السريع للمدير التنفيذي (Fast Pass) لتجربة فورية دون عناء.

2. **محاكي شجرة صمامات رأس البئر التفاعلي (Xmas Tree Simulator):**
   * رسم تشريحي تفاعلي لصمامات رأس البئر (Swab, Master, Wing, Choke Valves).
   * إمكانية النقر على أي صمام لعرض قراءات الضغط (PSI)، تاريخ التشحيم، واختبارات الإحكام.
   * استعراض وتحميل جواز البئر المعتمد (Well Passport PDF) وفق معايير API 6A.

3. **إدارة المستودعات وسلاسل الإمداد (WHM Stock Control):**
   * تتبع قطع الغيار والشحوم وموانع التسريب.
   * نماذج إصدار سندات الصرف (Goods Issue) وسندات الاستلام (Goods Receipt) الفورية.

4. **مصفوفة تدريب الكوادر الميدانية (Training Matrix):**
   * مطابقة كفاءات السلامة والسيطرة على الآبار (IWCF Level 4, H2S, NORM).
   * عرض وطباعة شهادات الكفاءة المعتمدة لكل مهندس وفني.

5. **السلامة وتصاريح العمل الإلكترونية (e-PTW & Radiation):**
   * تصاريح العمل الساخن والبارد ومتابعة انتهاء صلاحيتها.
   * سجلات قياسات الإشعاع لأجهزة الـ Dosimeters الميدانية.
